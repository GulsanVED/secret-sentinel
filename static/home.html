Secret Sentinel finds API keys, tokens, passwords, private keys and database credentials in a repository and its entire git history. Put it in CI to block new leaks at the pull request, or scan any repository right now.

Every push and pull request

Scan in CI

Runs automatically on GitHub Actions and fails the build on a new secret, so it cannot be merged.

Set up CI in a repository
  1. Copy ci/github-actions-secret-scan.yml into your repository as .github/workflows/secret-scan.yml.
  2. Optional: add SMTP or Slack secrets for alerts, a .sentinel-rules.json for your own token formats, and SENTINEL_BANDIT=true to also scan Python code for vulnerabilities.
  3. In branch protection, make the Secret scan check required.
